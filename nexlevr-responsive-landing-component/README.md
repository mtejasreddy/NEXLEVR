# NexLevr Responsive Landing Component

A responsive landing-page hero component built with HTML and CSS as part of the NexLevr Frontend Developer task.

## Preview

A clean, modern landing component featuring:

- Responsive navigation bar
- Hero heading and supporting text
- Primary and secondary call-to-action buttons
- Learning-progress visual card
- Desktop, tablet, and mobile responsive layouts
- Hover interactions for buttons and cards

## Built With

- HTML5
- CSS3
- Flexbox
- CSS Media Queries

## Responsive Design

The component was tested across:

- Desktop
- Tablet
- Mobile (375px width)

On mobile screens, the two-column hero layout changes into a stacked layout for better readability and usability.

## Features

- Semantic HTML structure
- Responsive navbar
- Flexible hero layout using Flexbox
- CSS `clamp()` for responsive heading sizes
- Hover effects for CTA buttons
- Interactive mini learning cards
- Accessible navigation label using `aria-label`
