# NexLevr CTA Animation

A CSS-only animated call-to-action button built as part of the NexLevr Frontend Developer proof-of-work task.

## Preview

This project contains a NexLevr-inspired CTA section with an animated **Start Learning** button.

## Animation Effects

When the user hovers over the CTA button:

- The button changes from black to blue
- The button lifts upward
- The arrow moves to the right
- A shine effect sweeps across the button

When the user clicks the button:

- The button briefly scales down to create press feedback
